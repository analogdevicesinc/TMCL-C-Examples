# TMC6460 TMC-API - C Examples

## Overview
This library is intended to be operated with [TMC6460-Eval V1.x](https://www.analog.com/en/products/tmc6460.html) (hereinafter referred to as Eval Board) and Arduino-based setups. In the example and the connection scheme mentioned, the representation is in context to Arduino Mega boards; however, the connections can be modified in order to operate the Eval Board with other versions of Arduino boards.

This example demonstrates open-loop and closed-loop control of a BLDC motor using the TMC6460 integrated motor control IC. The configuration is tuned for a QBL4208-61 motor with 4 pole pairs and an ABN incremental encoder with 1024 counts per revolution. The example configures the TMC6460 for field-oriented control (FOC), PI tuning, motor setup, and feedback handling.

## Usage
### Hardware
To use the eval board make the following connections between Arduino Mega and the Eval Board:

Arduino MEGA Pin | TMC6460 Pin | Signal
-----------------|-------------|------------------
51 (MOSI)        | 32          | SPI1_SDI
50 (MISO)        | 33          | SPI1_SDO
52 (SCK)         | 31          | SPI1_SCK
53 (SS)          | 30          | SPI1_CSN
14 (TX3)         | 21          | UART_RX
15 (RX3)         | 22          | UART_TX
06 (D6)          | 08          | DRV_EN
23 (D23)         | 19          | NSLEEP
GND              | 02          | GND
5V               | 05, 42      | +5V, +5V_VM

The encoder is wired as follows:

Encoder Signal | TMC6460 Pin
---------------|-------------
A (White)      | A+
B (Green)      | B+
N (Yellow)     | Z+

 ### Installing Libraries
 Adding the *TMC6460_TMC_API* library to your Arduino Libraries is quite a simple process, just follow these steps:
 1. Download the library from GitHub.
 2. Copy the TMC6460_TMC_API complete directory to *C:\Users\Your_User_Name\Documents\Arduino\libraries\TMC6460_TMC_API*
 3. Go to *TMC6460-TMC-API/examples/TMC6460_MOTOR_CONTROL_EXAMPLE* and open [TMC6460_MOTOR_CONTROL_EXAMPLE.ino](\examples\TMC6460_MOTOR_CONTROL_EXAMPLE\TMC6460_MOTOR_CONTROL_EXAMPLE.ino).
 4. Now, the code can be modified with respect to the application.

 ## Understanding the Code
 1. The Arduino code, [TMC6460_MOTOR_CONTROL_EXAMPLE.ino](\examples\TMC6460_MOTOR_CONTROL_EXAMPLE\TMC6460_MOTOR_CONTROL_EXAMPLE.ino), demonstrates motor control using the TMC6460 in both open-loop and closed-loop operation.
 2. `static TMC6460BusType activeBus = TMC6460_BUS_SPI;` is used as the default communication bus. It can be switched to `TMC6460_BUS_UART` by commenting and uncommenting the appropriate line.
 3. `tmc6460_autogeneratedExample(IC_ID);` configures the TMC6460 for a BLDC motor, sets the motor type, number of pole pairs, PWM configuration, ADC and CSA settings, current PI gains, limits, and ABN feedback configuration.
 4. `tmc6460_openLoop(IC_ID);` configures the device for open-loop velocity control and drives the motor with a flux target for a short interval.
 5. `tmc6460_closedLoop(IC_ID);` initializes the ABN encoder, forces the motor into a known position, clears the ABN count, and then applies forward and reverse torque targets for closed-loop operation.
 6. `setup()` initializes the communication interface, toggles `NSLEEP`, and enables the driver before starting the configuration steps.
 
 > Pin numbers should be changed in the code if the connection has been altered or if any other Arduino boards are being used.
